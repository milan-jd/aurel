# AUREL: concept build

A concept build: a premium D2C fragrance store for **AUREL No. 7, Ambre Lumière**. It is a portfolio piece by **Milan John Davis**.

**Live site:** https://milan-jd.github.io/aurel/

## What it shows

- A real-time 3D glass bottle (Three.js): refractive glass, brass cap and a liquid that changes colour per edition.
- Drag to turn the bottle, choose edition and size, and type an engraving that appears live on the label.
- A full add-to-bag flow: drawer, quantities, subtotal and a free-gift progress bar.
- Scroll-driven scent story with drifting petals, a horizontal ritual gallery, reviews, a Discovery Set and FAQ.
- Responsive layout with a sticky mobile buy bar.

## A reference build

This site is intentionally a minimal showcase. Client stores build on this foundation with real product photography, Shopify or custom checkout, CMS content and richer motion, all scoped to each brief.

## Run locally

Serve the folder with any static server (for example `python3 -m http.server`) and open it in a browser. `app.js` is the bundled build.
